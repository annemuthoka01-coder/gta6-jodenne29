Cielo Heat is an original top-down open-world crime game built in vanilla JavaScript using ES modules and a single 2D canvas, with zero external libraries and no network usage.

## How to Run

Start the static development server:

```bash
node serve.ts --port 8080
```

Then open `http://localhost:8080` in your browser.

## Controls

- **Movement / Steering**: `W`, `A`, `S`, `D` or Arrow Keys
- **Enter / Exit Vehicle**: `F` or `Enter`
- **Sprint / Handbrake**: `Shift` / `Space`
- **Attack / Shoot**: Mouse click
- **Cycle Weapons**: `Q` or `E`
- **Pause**: `Escape` or `P`

## Game Systems

- **Procedural Coastal City**: Grid-based streets, avenues, beach, sea, buildings, and palm trees.
- **Traffic & Pedestrians**: Autonomous citizens and vehicles populating the open world.
- **Vehicle Mechanics**: Carjacking, realistic driving physics, steering, and damage.
- **Wanted Heat System**: 5-star police pursuit and dynamic AI response.
- **Story Missions**: Multi-stage narrative campaign with objectives and rewards.
- **Combat & Audio**: Weapon arsenal, health/lives, and procedural WebAudio sound effects.
